## A. Readiness definitions (proposed — adjust if needed)

| Status          | Minimum criteria                                                                                                                                                                                                                                                                                 |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Ready**       | (1) At least one comparable project completed in the last 24 months (client work or an internal system in real production use); (2) a named team member who will deliver it; (3) Code Mindset can support it after launch; (4) the team can explain its process, typical constraints and limits. |
| **Partner-led** | (1) A named partner with a written agreement (subcontract + NDA); (2) the partner's capability checked (portfolio or reference); (3) Code Mindset owns client communication, QA and acceptance; (4) the partner's involvement is disclosed to the client.                                        |

**Public-page rule:** a service gets its own page only if it is Ready (or Partner-led with disclosure), has enough real substance to fill the service-page template, and has at least one evidence item: a permitted case study, a clearly labelled demo, or a detailed process artefact.
